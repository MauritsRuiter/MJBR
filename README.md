# MJBR Portfolio

Personal portfolio built with React and Vite. It brings together animated typography, scroll-driven sections, project work, and custom error pages.

## Features

- Rotating headline text and scroll-triggered text reveals.
- A horizontal services section with animated panels.
- A logo loop and visual effects such as Beams and LetterGlitch.
- React-rendered 403 and 404 views.

## Tech Stack

- React 19
- Vite 7
- Tailwind CSS 4
- GSAP and ScrollTrigger
- Motion for React

## Getting Started

Install a current version of Node.js and npm, then run:

```sh
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Available Scripts

```sh
npm run dev      # Start the development server
npm run build    # Create a production build in dist/
npm run preview  # Preview the production build locally
npm run lint     # Run ESLint
```

## Project Structure

- `src/App.jsx` assembles the portfolio sections and handles the error-page views.
- `src/` contains the React components, hooks, and imported assets.
- `public/` contains static files served from the site root and copied to the build.
- `dist/` is generated by `npm run build`.

## Customization

- Update rotating headline text and its appearance in `src/RotatingText.jsx`.
- Edit the scroll-revealed statement in `src/DynamicText.jsx`.
- Update portfolio content in `src/WhoAmI.jsx` and `src/MyWork.jsx`.
- Replace or add images and logos in `src/assets/`; place public files such as fonts in `public/`.
- Adjust utility classes in the components to change layout, spacing, and colors.
